# Personal Portfolio

A modern personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

It showcases my background, projects, skills, experience, certifications, and journey in software development and cybersecurity.
## Run Locally

```bash
git clone <your-repository-url>
cd <your-project-folder>
npm install
npm run dev
```
Open http://localhost:3000 in your browser.
